Page: the example flags on a placed on the market submission (EB-325). Both versions of the submission page use these, so a change here shows everywhere.

Each flag has 5 labels: member, type, what we found, figures and reason.
To add a flag, copy a whole flag (all 5 labels), change the number (Flag 4, Flag 5 and so on) and change the words. Up to 10 flags.
To remove one, delete all 5 of its labels.
Type is Irregularity or Variance (other types show as a grey tag).
Figures only show on the full version. Leave them empty if there are none.
Done? Select Commit changes. It's live in about 5 minutes.
