Move the Welsh language link below the beta banner

Change

The Welsh language link now sits below the beta banner, on the right, on every regulator page. It was in the service navigation.

Why

  • It's in the same place as the regulator toolkit prototype (opens in new tab)'s link, so regulator services stay consistent
  • The service navigation stays free for menu items, the signed-in person and Sign out
  • The GOV.UK language navigation guidance (opens in new tab) says to choose a single consistent location that works for your users. The service navigation is one option, not a rule

What hasn't changed

  • It's still the GOV.UK language navigation component (in trial), with only GOV.UK override classes to place it
  • It's still its own navigation landmark ("Language"), so screen reader users can find it
  • Cymraeg is still marked as Welsh, so screen readers say it in Welsh (WCAG 3.1.2, language of parts)
