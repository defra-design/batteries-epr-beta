Add the placed on the market submissions page, in two versions to compare

New

Regulators need one place to see which compliance schemes have sent their placed on the market data, and what needs reviewing first. We don't know yet whether they want one quarter at a time or everything, so there are two versions to test.

Both versions

  • The 4 real compliance schemes, with dummy dates and statuses
  • Quarters in words ("July to September"), not "Q3"
  • Columns: scheme, date submitted, due, status, and a link to the submission
  • Statuses: To review, In progress, Query raised, Review response, Accepted. An overdue return has a red Overdue tag next to its due date
  • Scheme names and "View submission" go to a holding page for now: those pages aren't built yet
  • Only the table scrolls sideways at small widths, not the page

Version A: latest quarter

  • Opens on the latest quarter with submissions (July to September 2026), with year and quarter filters
  • Always 4 rows, soonest due first

Version B: all submissions

  • Opens on everything from 2024 to 2026 (44 submissions), with year, quarter and status filters, and a line saying what's showing
  • An extra quarter column, and every column sorts
  • All on one page. Sorting wouldn't work across pages, so a real service with more years would need to sort on the server

Not in this version

  • Members, versions and flags columns (members and flags move to other pages)
  • Tabs for waste and evidence

  • Version B: all submissions
