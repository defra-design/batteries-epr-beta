Update statuses, overdue and empty cells on the placed on the market submissions pages

Change

Jen updated the statuses and how overdue returns look.

Statuses

  • To review, Under review, Query raised, Response received, Accepted and Escalated, in the table and the status filter (version B)
  • New tag colours, because two of the old ones don't exist in GOV.UK Frontend 6, so To review and In progress looked the same. See the GOV.UK tag component (opens in new tab)
  • No red status tags

Overdue

  • "Overdue" in bold black text above the review by date, in both versions
  • Not red: in GOV.UK services red text means an error. See the GOV.UK error message component (opens in new tab)
  • We tried a red tag in version A first, but bold black text looks better and is clear enough

Empty cells

  • Once a return is accepted there's nothing to review, so the Review by cell is empty on screen. Screen readers hear "Not applicable", as the regulator toolkit does, instead of "blank"

Kept as they are

  • Short months in the table ("Jul to Sep 2026"), in full in the filters. The GOV.UK style guide (opens in new tab) allows short months in tables when space is tight

Next

  • Late submissions: we'll show these on the submission page as a flag, for example "Submitted 3 days late", not in this table

Pages

  • Version A: latest quarter
  • Version B: all submissions
