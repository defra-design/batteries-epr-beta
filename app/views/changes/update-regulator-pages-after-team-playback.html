Update the placed on the market pages after the team playback

Change

On 16 November we played EB-324 to EB-326 back to the team. These are the changes from that playback, and why. They won't go into build until after user research, so we can still change them when we hear from regulators.

Submissions list (both versions)

  • The scheme name is now a link to the scheme's organisation details for that quarter. Who the admin is, and who can submit, can change over time, so the details belong with the quarter
  • "View submission", not "View": with two links in a row going to two different places, each link needs to say where it goes

Headings

  • The submission, organisation details and members pages all follow the same pattern: the scheme name in the caption, then a heading that starts with the quarter and says what the page is. For example "July to September 2026 submission", "July to September 2026 organisation details" and "July to September 2026 members"

Submission (both versions)

  • No Organisation section: you get to the organisation details from the scheme name on the list instead
  • Members (how many, with View members) is now in the submission details: they're the members in that quarter's return

Organisation details

  • Reached from the scheme name on the list, and Back goes to that list
  • The heading starts with the quarter, for example "July to September 2026 organisation details". The caption above it is the scheme name
  • No Members row: members are reached from the submission, so there's one way there, not two

Members

  • No Flags column and no "Only members with flags" checkbox: the flags are on the submission page, so this page is for finding members
  • The heading starts with the quarter, for example "July to September 2026 members". Members can join and leave, so it needs to be clear they're the members for that quarter. Was: "Search for a member"

Flags

  • "Same tonnage as last quarter" isn't a variance, so it's gone. A placeholder irregularity takes its place until content design rewords the examples
  • The example flags are now in their own words file (app/content/regulator/flags.md), used by both versions of the submission page, so content design can change them, or add more, in one place

Review dates (lists and submission)

  • One date column on the lists, Review by: the date the regulator needs to review the return by, 10 days after the scheme submitted it
  • Under the date, the time left: "3 days left", "Due today", or "Overdue by 3 days" in bold. So the team can see at a glance what needs doing first, and how long they've got, without keeping a spreadsheet to count the days
  • No Submitted column on the lists. The Submitted date is still on the submission, where it explains the review date
  • The submission shows Review by in the same way, with the time left
  • Once a return is accepted, there's nothing to review, so there's no review date
  • Content design may still change the column heading and the wording of the time left
  • The example returns show each case once: overdue by 3 days, due today, 7 days left, and accepted. The old escalated return from April to June 2026 is now accepted: it was overdue by 101 days, which would throw people in research

For research

  • We'll suggest testing the brief versions with regulators. The full versions stay in the prototype
